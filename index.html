من هي AGENT X؟

AGENT X وحدة عمليات سرية تم إنشاؤها لتنفيذ المهام الحساسة التي تتطلب أعلى درجات السرية والانضباط. وجود الوحدة غير معلن للعامة، ولا يتم الكشف عن أعضائها أو مهامها إلا بتصريح من قيادة X.

التبعية

الجهة الوحيدة: X

AGENT X ليست فرقة مستقلة وليست تابعة لأي منظمة أخرى. مصدر الأوامر والصلاحيات هو قيادة X فقط.

الطبيعة

  • وحدة سرية
  • صلاحية محدودة ومعروفة للقيادة
  • هوية الأعضاء غير معلنة
  • المعلومات مصنفة سرية

الاختصاص

التعامل مع المهام الخاصة، جمع المعلومات، الدعم السري، والعمليات التي تحددها قيادة X ضمن قوانين السيرفر والـRP.
